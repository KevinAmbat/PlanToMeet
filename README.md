# PlanToMeet

This app has users post suggestions of things to do which populates a group chat for anyone to collaborate on. People or clubs can pick up the "project" and once certain 
initial conditions the initial host set up are met (minimum headcount, budget, etc.) then finalizations are made. The suggestion becomes an actual event people can join/RSVP. 
The users can check in to the event once they arrive, because there is a tracker of their attendance to events.

**Demo/screenshot**

Problem it Solves
Instead of the organizer bearing all of the weight of a project (which they can choose to do if they are capable), others assume responsibility in the project to make it happen. 
This follows the natural strength of people to organize if they are supported by others.
